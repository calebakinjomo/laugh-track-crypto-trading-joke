One joke about crypto and trading life, under 200 characters, for make.fun's "Laugh Track: The Crypto Trading Joke Contest" bounty ($2 in USDC). A judge model reads the entries two at a time and picks the funniest.

## The joke

> I bought the dip, then the dip dipped, then the dip's dip dipped — my portfolio is now a Russian doll of bad decisions.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes the joke to `out/entry.txt`. Python 3 standard library only.
